### Summary

- **Path length:** 9 steps from `main()` to `ExtractContent`.
- **Edge types encountered:** `direct-function-call`, `struct-literal-field-assignment`, `http-handler-registration` (a specialization of `callback-registration` over a method value with a statically-known concrete receiver).
- **Hardest edge:** Step 6, the `http-handler-registration` at `internal/ui/ui.go:106`. It is the only edge that traverses a callback boundary: the method value `handler.fetchContent` is handed to `net/http.ServeMux`, and the actual invocation happens later when the mux dispatches a matching request. A static analyzer must recognize `*ServeMux.HandleFunc` (and `Handle`) as registration sinks and treat the registered value as reachable from the server's `ListenAndServe` loop. Once that pattern is modeled, the edge is fully resolvable: the receiver is the concrete `*handler` constructed at `internal/ui/ui.go:26`, so there is no interface dispatch, no reflection, and no plugin lookup involved.
- **Static-analysis feasibility:** Fully feasible. Every edge on the shortest path is either a direct cross-package call or a `net/http.ServeMux` registration with a statically-known method value over a concrete receiver — no `reflect`, no `plugin`, no runtime-supplied function pointers, and no interface dispatch on the path. A whole-program call-graph builder that models `net/http.ServeMux.{Handle,HandleFunc}` as a callback sink can connect `main` to `ExtractContent` end-to-end.

Same shape and same length as the UI path; uses the same `http-handler-registration` mechanism inside `api.NewHandler`.
  - **Feed-refresh paths** — `processor.ProcessFeedEntries` is reachable from `internal/reader/handler/handler.go:86, 189, 329` (subscription discovery / refresh). These are reached via the API/UI handlers and additionally from the worker pool / scheduler started in `internal/cli/daemon.go` (`worker.NewPool` at line 30, `runScheduler` at line 33). Those paths are strictly longer than the UI/API direct fetch paths (they add a goroutine launch and a channel-based worker dispatch), so they are not the minimal path.
