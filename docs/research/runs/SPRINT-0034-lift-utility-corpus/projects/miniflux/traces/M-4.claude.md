### Summary

- **Path length:** 5 steps.
- **Edge types encountered:** `direct-function-call`, `goroutine-launch-of-anonymous-closure`, `goroutine-launch-of-named-function`.
- **Hardest edge:** Step 3 (the worker-pool goroutine launch). Statically the closure body is visible at the launch site, so the call graph edge is resolvable by syntax, but a static analyzer that wants to model concurrency precisely must (a) recognize that the goroutine's lifetime is gated by the `jobQueue` channel filled at refresh_feeds.go:67-70 and closed at line 70, and (b) treat the `range` over the channel as a generator of `model.Job` values whose origin is `batchBuilder.FetchJobs()`. Neither piece is required to *connect* the entrypoint to the region root, but both matter for any per-call instrumentation that needs to identify which physical call site a goroutine's `RefreshFeed` invocation came from.
- **Static-analysis feasibility:** Fully resolvable with import-graph + identifier lookup; no interface dispatch, no reflection, no plugin loading anywhere on this path. Both goroutine launches use directly named callees, so the call graph is intact across the goroutine boundaries — the compiler only needs to remember that the callee runs concurrently, not to discover which callee it is.
- **Alternative paths (not the shortest, mentioned for completeness):**
  - **Daemon / worker-pool path:** `main` → `cli.Parse` → `startDaemon(store)` (cli.go:248) → `(*worker.worker).Run` (worker/worker.go:24, started as a goroutine via a method value) → `feedHandler.RefreshFeed` (worker.go:40) → `go integration.PushEntries` (handler.go:349). Adds a method-value-on-concrete-receiver edge plus the daemon wiring; longer than the CLI path.
  - **HTTP API path:** `main` → `cli.Parse` → `startDaemon` → HTTP server → mux handler registration → `feed_handlers.go:67` calls `feedHandler.RefreshFeed` → `go integration.PushEntries`. Adds the http-handler-registration edge and the server boot, so longer still.
  - **UI path:** Symmetric to the API path through `internal/ui/feed_refresh.go:21`.
