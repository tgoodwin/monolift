- **Correct:** partially - The `createEphemeralPost` path is real: `post.go:28` registers it, `post.go:215` calls `PreparePostForClientWithEmbedsAndImages`, and the metadata pipeline reaches `post_metadata.go:934 -> :1021`. The trace skips the `runServer` -> `server.Start()` edge and compresses `api4.Init` route construction into `InitPost`, so the HTTP activation carrier is under-specified.

Do not add the earlier `SendEphemeralPost` call at `post.go:211`; it is runtime order, but the static shortest call edge from this handler is the direct call at `:215`.

Both traces converge after `getEmbedsAndImages`: `getEmbedForPost` -> `getLinkMetadata` -> the conditional URL fetch branch at `post_metadata.go:934` -> `getLinkMetadataForURL` at `:1021`.
