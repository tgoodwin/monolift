## Cross-trace observations

The traces converge on the initial server and hub setup (Steps 1-6) but diverge in how they reach the region root from the hub's processing loop. Claude (and gemini) follows the minimal path through the hub's startup and the default message-send case, while Codex provides a longer, more exhaustive path through the HTTP API and the "clear notification" flow. Claude's trace is the canonical minimal path.
