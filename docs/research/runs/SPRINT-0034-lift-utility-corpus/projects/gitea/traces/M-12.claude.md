### Summary

- **Path length:** 10 steps from `main()` to the region root.
- **Edge types encountered:** `struct-literal-field-assignment`, `direct-function-call`, `function-passed-as-parameter-then-invoked`, `goroutine-launch`, `channel-send-receive` (via typed work queue), `function-value-in-struct-field`, `interface-method-dispatch`.
- **Hardest edge:** Step 7→8, the queue handoff combined with the `safeHandler` function-value field dispatch in step 8. The compiler must (a) match the producer's `Push` to the consumer worker spawned by `RunWithCancel(statsQueue)` for the *same* `*WorkerPoolQueue[int64]` instance, and (b) resolve `q.safeHandler` field-sensitively to the `handler` registered in `CreateUniqueQueue`. Both are tractable but require object-sensitive (per-allocation) flow analysis on the singleton `statsQueue`. The interface dispatch in step 9 is also non-trivial but easier because the interface variable has exactly one writer.
- **Static-analysis feasibility:** Resolvable end-to-end with standard whole-program techniques — type analysis for the build-tagged file selection, field-sensitive flow for the `cli.Command.Action` and `WorkerPoolQueue.safeHandler` function-value fields, and CHA/RTA for the `Indexer` interface (single implementer reachable). The only fundamentally concurrent edge is the queue handoff (step 7→8), which is statically resolvable for *what* gets called but not for ordering — a Monolift dispatch decision can still be wired in at the `safeHandler` invocation site or directly inside `(*DBIndexer).Index` without needing to reason about scheduling.
- **Alternative paths (briefly):** The same `statsQueue → handler → indexer.Index → (*DBIndexer).Index → GetLanguageStats` tail is also reached from (i) HTTP handler `routers/web/repo/setting/setting.go:703` (`stats.UpdateRepoIndexer` on an admin "reindex" form post) and (ii) the notify-service hooks in `services/indexer/notify.go:82,95,108,117` (called on repo migrate/push/sync-push/default-branch-change via the `Notifier` interface registered in `services/indexer/indexer.go:15`). Both add HTTP-routing or observer-callback edges on top of the tail and so are strictly longer than the startup-population path traced above.
