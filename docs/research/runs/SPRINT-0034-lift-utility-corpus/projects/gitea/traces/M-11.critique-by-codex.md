## Critique of gemini's trace

### Path
- **Correct:** yes — The path follows the real production web-command route from `main` to `getIssueIndexerQueueHandler`, and the checked Gitea file:line citations are accurate.
- **Minimal:** no — Steps 1-3 are an inflated representation of the CLI dispatch; the compiler-relevant edge is the function value stored in the command `Action` field and invoked by the CLI framework. The rest is minimal except for optionally treating the nested handler-factory call as a distinct argument-call shape.

### Edge types
| Step | gemini's label | Verdict | Suggested label (if different) | Reasoning |
|---|---|---|---|---|
| 2 | `method-call-on-concrete-type` | OK but non-minimal | — | Accurate for `app.Run(ctx, args)`, but this intermediate framework entry can be folded into the CLI action-dispatch edge in a minimal trace. |
| 3 | `callback-dispatch` | RENAME | `function-value-in-struct-field` | `callback-dispatch` is too coarse for a compiler schema; the needed mechanism is field-sensitive tracking from `cli.Command{Action: runWeb}` to the later field invocation. |
| 6 | `function-value-call` | RENAME | `function-parameter-callback` | The analyzer must propagate `indexer_service.Init` through the `mustInit(fn func() error)` parameter and resolve the `fn()` call, not merely recognize a generic function-value call. |
| 8 | `direct-function-call` | OK, optional precision | `direct-function-call-as-argument` | The call to `getIssueIndexerQueueHandler(ctx)` is direct but nested as the queue-constructor argument that supplies the handler. |

### Other notes
`callback-dispatch` is codebase-agnostic, but too broad: it loses the distinction between struct-field callbacks, parameter callbacks, interface dispatch, and framework command-table selection.

## Cross-trace observations

Both traces converge on the same real route after `runWeb`: `serveInstalled` -> `InitWebInstalled` -> `mustInit(indexer_service.Init)` -> `InitIssueIndexer` -> `getIssueIndexerQueueHandler`. They mainly diverge from the canonical minimal path by expanding the CLI framework call into separate direct/method/callback steps; Gemini is slightly cleaner on the `mustInit` target, while Claude uses the better CLI edge label. The closest canonical shape is the collapsed six-step path with `function-value-in-struct-field` for CLI dispatch and `function-parameter-callback` for `mustInit`.
