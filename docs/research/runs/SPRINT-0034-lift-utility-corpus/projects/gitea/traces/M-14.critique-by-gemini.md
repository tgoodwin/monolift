## Cross-trace observations

All traces converge on the `Notify` -> `notify` -> `DetectWorkflows` tail, confirming this as the canonical entry point for Actions logic regardless of the triggering event. Claude provides the most minimal request-flow path by selecting `CreateIssue`, which avoids the background worker queues present in push-based paths. Codex provides the most detailed resolution logic by explicitly tracing the notifier registration. Claude's trace is the most efficient for a compiler's reachability analysis, whereas Codex's trace better illustrates the whole-program value-flow requirements.
