## Cross-trace observations

The traces converge on the high-level architecture: Cobra CLI dispatch -> `apis.Serve` -> Router setup -> HTTP handler registration. They diverge on the specific API route: Claude and Gemini use the primary `auth-with-password` route (which includes a hook-dispatch step), while Codex uses the `auth-with-otp` route which is statically simpler. Gemini provides the most connected and verifiable path, whereas Claude collapses the CLI dispatch engine and Codex's trace fails linearity.
