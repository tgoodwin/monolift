## Cross-trace observations
All traces converge on the primary activation path from `main` to the API registration logic (`bindRecordAuthApi`). The meaningful divergence lies in granularity: Gemini and Codex use higher-level pattern labels like `http-handler-registration`, while Claude decomposes the router's internal dispatch into field assignments and closure invocations. Claude's trace is the closest to a "canonical minimal path" for a compiler because it exposes the actual data-flow links that a points-to analysis would need to traverse.
